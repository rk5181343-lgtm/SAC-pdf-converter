Before you share the URL

Privacy and access

  • No sign-in. The workspace opens straight into the tools. There is no administrator, no team screen and no per-person account.
  • One shared library. Every batch is filed under the workspace itself, so anyone using the app sees the same history and can download any file in it.
  • Files stay server-side. Uploads and outputs are stored in the workspace so a user who loses a laptop can download them again. Files are served only through the app's own routes; there are no public file URLs.
  • Protect the URL. Anyone who reaches it can upload, convert and read every file. On Vercel, turn on Deployment Protection or put the app behind your network.
  • The library lives in the database. Without DATABASE_URL the app uses an ephemeral SQLite file: the history is cleared whenever the instance is recycled.

Conversion never sends document contents anywhere. The optional Exa lookup sends only what you type into its box.
